# Campfire

마인크래프트 서버를 클릭 한 번으로 여는 Windows용 런처입니다.
자바 설치나 포트포워딩 없이, 켜기만 누르면 친구들이 들어올 주소가 생깁니다.

- 소개와 다운로드: https://campfire.o-r.kr
- 최신 설치 파일: [Campfire-setup.exe](https://github.com/Ccaan6/campfire/releases/latest/download/Campfire-setup.exe)

이 저장소는 설치 파일 배포용입니다. 한 번 설치하면 이후 버전은 런처가 스스로 업데이트합니다.
